安全头设置

    • Content-Security-Policy：防止跨站脚本和数据注入攻击。
    • X-Content-Type-Options: nosniff：阻止浏览器 MIME 类型猜测。
    • X-Frame-Options: DENY：防止点击劫持攻击。
    • Strict-Transport-Security：强制使用 HTTPS 访问。
